# SearchField

Recherche globale en pilule, dans l'en-tête de Ma journée : tâches, notes et réunions.

Composant ajouté par la direction Mymind.

## Mesures

Hauteur 38, rayon `pill`, contour `borderDefault` sur `surfaceDefault`, loupe de 15, texte `body` en `textSecondary`, raccourci ⌘K à droite. 240 de large au moins.

## Comportement

⌘K donne le focus depuis n'importe quel écran ; les résultats s'ouvrent sous la pilule, groupés par Tâches, Notes, Réunions. Échap ferme.

## Ce que fournit l'appelant

La requête liée et la liste de résultats.
