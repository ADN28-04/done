Done, design system v5

Un outil de travail net : du papier neutre, un graphite pour le texte, un indigo pour ce qui agit, une brique pour les seules alertes. Une famille, Archivo, porte toute la typographie ; sa largeur semi-étroite donne sa voix à la prochaine action.

Principes

Une seule chose forte par écran : la prochaine action en titre étroit, ou le minuteur en chiffres fins. Le reste se tait. Pas d’ombre sur les cartes, pas de fond derrière les dates et les durées, pas de capitales espacées : les étiquettes sont en casse normale. Les nombres utilisent les chiffres tabulaires d’Archivo, jamais une police à chasse fixe.

Couleurs

Les noms de marque (Papier #F6F6F7, Graphite #1C1E26, Indigo #4553A0, Pervenche #AAB4F2, Brique #A3332E) ne figurent jamais dans le code : il utilise les rôles de DoneColor. Toutes les paires texte et fond passent AA.
